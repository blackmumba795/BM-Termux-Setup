BLACK MUMBA is a professional Python-based setup tool for Termux that automates the installation of essential packages, security tools, and utilities for ethical hackers and programmers.

## 📋 Features

- **One-Command Full Setup** - Complete Termux environment configuration
- **Modular Installation** - Install only what you need
- **Security Tools** - Nmap, Hydra, Nikto, SQLMap
- **Development Tools** - Python, Git, clang, make, cmake
- **Extra Utilities** - 50+ everyday tools (htop, neofetch, tmux, etc.)
- **Python Modules** - Popular libraries for hacking and development
- **System Optimization** - Performance tweaks for Termux
- **Auto-Fix** - Repair broken Termux installations

## 🚀 Installation


# Clone the repository
```python
git clone https://github.com/blackmumba795/BM-Termux-Setup.git
cd BM-Termux-Setup
```
# Make the script executable
```python
chmod +x BM-Termux-Setup
```

# Run the script
```python
python3 setup.py
```
